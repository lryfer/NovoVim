# Neovim Keybindings

## Leader Key
`Space`

## LSP
`K` : hover documentation
`gd` : go to definition
`gD` : go to declaration
`gi` : go to implementation
`gr` : find references
`gt` : go to type definition
`<leader>ca` : code actions
`<leader>rn` : rename symbol
`<leader>sh` : signature help
`[d` : previous diagnostic
`]d` : next diagnostic
`<leader>e` : show diagnostic float
`<leader>q` : diagnostic quickfix list

## Refactoring
`<leader>re` : extract function (visual)
`<leader>rf` : extract to file (visual)
`<leader>rv` : extract variable (visual)
`<leader>ri` : inline variable
`<leader>rI` : inline function
`<leader>rb` : extract block
`<leader>rbf` : extract block to file

## Formatting
`<leader>cf` : format buffer

## Telescope
`<leader>ff` : find files
`<leader>fg` : live grep
`<leader>fb` : find buffers
`<leader>fh` : help tags

## File Tree
`<leader>tt` : toggle file tree

## FTerm
`<Alt-i>` : toggle floating terminal
`<leader>x` : quick command (single command with output)

## Trouble
`<leader>xx` : diagnostics
`<leader>xX` : buffer diagnostics
`<leader>cs` : symbols
`<leader>cl` : LSP definitions/references
`<leader>xL` : location list
`<leader>xQ` : quickfix list

## Debug (DAP)
`<leader>db` : toggle breakpoint
`<leader>dB` : conditional breakpoint
`<leader>dc` : continue/start
`<leader>dn` : step over
`<leader>ds` : step into
`<leader>do` : step out
`<leader>dd` : toggle debug UI
`<leader>dr` : open REPL
`<leader>dw` : add watch expression

## Completion (nvim-cmp)
`<C-n>` : next item
`<C-p>` : previous item
`<C-d>` : scroll docs down
`<C-u>` : scroll docs up
`<C-Space>` : trigger completion
`<CR>` : confirm selection
`<Tab>` : next item
`<S-Tab>` : previous item
